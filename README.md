# Kubernetes Platform Lab

Production-oriented Kubernetes experiments focused on platform engineering,
operations, reliability, and troubleshooting.

## Purpose

This repository will be used to build, operate, break, and troubleshoot
Kubernetes-based systems.

## Focus Areas

- containers
- Kubernetes architecture
- Pods and Deployments
- Services and networking
- ConfigMaps and Secrets
- probes
- resource requests and limits
- scheduling
- storage
- RBAC
- Helm
- rollouts and rollback
- production failure scenarios

## Planned Failure Scenarios

- CrashLoopBackOff
- OOMKilled
- Pending Pods
- DNS failures
- broken rollouts
- RBAC permission failures
- storage issues

## Troubleshooting Method

**Symptom → Hypothesis → Evidence → Root Cause → Fix → Verification → Prevention**

## Engineering Principle

> Build → Break → Diagnose → Fix → Document
